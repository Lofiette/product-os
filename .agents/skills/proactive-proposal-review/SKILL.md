# proactive-proposal-review

## Purpose

Filter proactive ideas so the team improves quality without uncontrolled scope creep.

## Procedure

1. Classify proposal: quality fix, craft improvement, product opportunity, risk mitigation, exploration idea.
2. Check evidence level: evidence, assumption, hypothesis, taste judgment, generated idea.
3. Estimate cost and complexity.
4. Identify affected roles, skills, gates, and artifacts.
5. Decide: approve now / ask user / backlog / reject / block.

## Output schema

```markdown
## Proactive Proposal Review

| Proposal | Class | Evidence level | User value | Cost | Scope impact | Decision |
|---|---|---|---:|---:|---|---|

### Required approval questions
```

## Rule

No proactive proposal changes approved scope without explicit user confirmation.
