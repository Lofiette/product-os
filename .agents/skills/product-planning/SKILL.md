# Skill: product-planning

## When to use
Use to turn a goal into MVP scope, acceptance criteria, and product plan.

## Procedure
1. Define user/customer problem and why now.
2. Define target users, situations, jobs, pain, and desired outcome.
3. Separate user outcome, business outcome, and build output.
4. Slice MVP: smallest end-to-end learning or value loop.
5. Define non-goals and explicit deferrals.
6. Define success metrics and qualitative signals.
7. Translate scope into acceptance criteria and verification needs.
8. Hand off research gaps, UX needs, technical risks, and delivery sequence.
