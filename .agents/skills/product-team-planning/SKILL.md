---
name: product-team-planning
description: Use after intake to coordinate selected specialist roles and create an evidence-backed implementation plan.
---

Process:

1. Read `TASK.md` and selected role playbooks.
2. Spawn or simulate only selected specialist roles.
3. Each role returns evidence-backed findings.
4. Consolidate into one plan.
5. Separate now/next/later.
6. Define tests and verification.
7. Request approval before implementation.

Output:

1. Executive summary
2. Findings by role
3. Recommended scope
4. Implementation plan
5. Verification plan
6. Risks and mitigations
7. Approval request
