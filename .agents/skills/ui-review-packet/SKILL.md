Follow `docs/UI_REVIEW_PACKET.md`.

Required output:
- Target URL/route
- Work mode
- Design-system mode
- Evidence list
- Changed files
- Relevant DS/component sources
- Review focus
- Reviewer limits
- Missing evidence

If key evidence is missing, ask for it or mark `INSUFFICIENT EVIDENCE`; do not start broad subagent review.
