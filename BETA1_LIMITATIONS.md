# Beta 1 limitations

This package is offline-certified. Its deterministic fixtures, runtime contracts, migration safety, package integrity and evaluation harness have been exercised without external services.

It does not yet certify:

- live Codex model choice quality;
- real subagent event ordering and cancellation delivery;
- native reconnect behavior across Codex clients;
- native macOS, Windows and WSL execution in this build environment;
- real token, latency and cost budgets;
- screenshot-based visual fidelity grading;
- organization-managed permission and plugin policies.

External services remain optional. The core continues to work with local files, Git and Python only.
