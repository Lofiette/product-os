# Product OS на русском языке

Основная русскоязычная документация теперь находится на главной странице репозитория: [README.md](README.md).

Этот файл сохранён, чтобы старые ссылки на `README_RU.md` продолжали работать.

Краткий путь установки Product Designer в Codex:

```bash
codex plugin marketplace add Lofiette/product-os --ref v4.1.0
codex plugin add cpt-core@product-os
codex plugin add cpt-design-ui@product-os
```

После установки откройте новую задачу Codex.
