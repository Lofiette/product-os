# Alpha 5 Limitations

- Knowledge freshness scans are deterministic but not yet connected to Codex hooks.
- Canonical knowledge uses file-backed YAML; SQLite arrives in a later phase.
- Markdown projections are generic and functional, not presentation-polished.
- The CLI does not infer product knowledge from code automatically; discovery remains skill-driven and approval-scoped.
- Semantic retrieval, MCP adapters, and external memory services are not included.
- Knowledge claims are validated structurally and semantically, but live-model authoring quality still needs executable evals.

- Sensitive-value scanning is heuristic defense in depth; it does not replace repository secret scanners, privacy review, or access control.
