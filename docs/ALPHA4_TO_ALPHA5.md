# Alpha 4 to Alpha 5

Alpha 5 adds a typed Product Knowledge lifecycle on top of the Alpha 4 role/skill/gate layer.

Added:

- canonical YAML knowledge index and artifacts;
- deterministic Markdown projections;
- existing, greenfield, and redesign modes;
- claim lifecycle and evidence-depth validation;
- source revisions, ownership, dependencies, and review triggers;
- targeted stale detection and dependency propagation;
- task-driven knowledge accounting before Standard Task completion;
- context packet generation;
- soft size guidance without truncation.

No new logical roles or domain skills were added.
