
# Alpha 5 to Alpha 6

Alpha 6 adds deterministic enforcement without changing the canonical Product Knowledge model.

New managed runtime asset: `.cpt/enforcement.yaml`.
New plugin assets: CPT Core lifecycle hooks.
New optional assets: conservative/strict command rules and permission-profile examples.

Update preserves tasks, leases, checkpoints, Product Knowledge, enforcement mode, audit logs, and worker records. Existing installations default to enforcement `off` until explicitly enabled.
