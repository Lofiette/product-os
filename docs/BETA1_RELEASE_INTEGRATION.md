# Beta 1 Release Integration

Beta 1 converts the 4.0 engineering package into a safely adoptable system.

Release invariants:

- core remains self-contained;
- external integrations stay optional;
- migration is plan-first and reversible;
- no project-specific names are present in universal assets;
- local and team modes remain distinct;
- personal plugin lifecycle is not conflated with project rollback;
- migration evidence is not silently promoted to canonical Product Knowledge;
- CI exercises migration on Linux, macOS and Windows.
