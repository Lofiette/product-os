# Chronicle Compaction

`CHRONICLE.md` is a compact rescue summary, not a timeline or transcript.

## Keep

- current active ticket or none;
- completed recent milestone;
- current blockers;
- available product knowledge artifacts;
- next workflow;
- safety state.

## Remove or archive

- repeated dated update ladders;
- long step histories;
- tool outputs;
- old decisions that no longer change the next action;
- implementation details already captured in product knowledge or task files.
