# CREATIVE_METHODS.md

Creative methods generate candidates, not evidence.

Use when quality may improve and the method can change a decision.
- Focal objects: unexpected product/UI ideas.
- Synectics: analogies from other domains.
- SCAMPER: systematic variants.
- TRIZ-lite: contradictions.
- Morphological matrix: parameter combinations.
- Six Thinking Hats: perspective check.
- Design Studio/Crazy 8s: UI concept spread.
- Pre-mortem/inversion: failure discovery.
- Opportunity Solution Tree: opportunity-to-solution link.

At most one creative loop per planning cycle unless the user requests ideation sprint.
