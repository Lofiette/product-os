# CREATIVE_METHODS.md — Quality-Improving Creative Protocols

Creative methods are optional improvement tools. They are used to generate better alternatives, reveal hidden assumptions, and improve decision quality. They are not evidence and they do not bypass risk gates.

## When to activate a creative loop

Activate only when at least one is true:
- the solution space is weak, obvious, or prematurely narrowed;
- the user asks for better ideas, breakthrough options, differentiation, or a creative review;
- a new stakeholder idea, research insight, support signal, market signal, or technical discovery may improve the plan;
- the team is choosing between multiple approaches and needs structured alternatives;
- the task is Prototype, Strategy, MVP, UX/UI, product discovery, or experience redesign.

Do not activate for Tiny/Fast Lane unless the user asks or the creative output can change the exact requested decision.

| Situation | Method | Best owner | Output |
|---|---|---|---|
| Need unexpected product ideas | Focal Objects | Product Strategist + relevant owner | Attribute-transfer idea set |
| Need analogies from distant domains | Synectics | Product Strategist / UX Researcher / Visual Design | Analogical solution candidates |
| Need systematic variation | SCAMPER | Product Strategist / UX Interaction Reviewer | Variation matrix |
| Need solve a contradiction | TRIZ-lite | Solution Architect / Design System / Product | Contradiction and resolution options |
| Need explore many combinations | Morphological Matrix | Team Architect + relevant specialists | Option grid and shortlist |
| Need critique from perspectives | Six Thinking Hats | Team Architect / Consistency Auditor | Balanced decision review |
| Need fast UI options | Crazy 8s / Design Studio | UX Interaction / Visual / Design System | Concept set and selection rationale |
| Need reverse-risk discovery | Inversion / Pre-mortem | QA / Security / Delivery / Product | Failure paths and mitigations |
| Need map opportunity choices | Opportunity Solution Tree | Product Strategist / Research | Opportunity → solution → experiment map |
| Need improve content | Content pattern remix | UX Writer | Message alternatives and tone fit |

## Creative loop protocol

1. Define the decision to improve.
2. State constraints and non-goals from `TASK.md`.
3. Pick one method only, unless the user asks for a creativity sprint.
4. Generate candidates without judging too early.
5. Filter using user value, feasibility, evidence, risks, accessibility, privacy/security, and verification.
6. Shortlist 1–3 options.
7. Mark all creative outputs as hypotheses until validated.
8. Hand off to owners for feasibility, UX, risk, or testing.
9. Update `TASK.md` only if the chosen option changes scope, acceptance criteria, risks, or plan.
10. Log material decisions in `CHRONICLE.md`.

## Guardrails

- Do not invent market facts or user insights.
- Do not turn creative hypotheses into acceptance criteria without approval.
- Do not add scope because an idea is interesting.
- Do not use creativity to bypass accessibility, privacy, security, performance, or release gates.
- Prefer one high-leverage creative pass over many decorative exercises.
