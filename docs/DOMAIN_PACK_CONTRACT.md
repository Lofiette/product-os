# Domain Pack Contract

A domain pack is optional and independently enabled.

Requirements:

- native plugin manifest;
- matching `cpt-pack.json`;
- stable kebab-case name;
- no ownership of canonical runtime state;
- precise skill triggers;
- explicit core compatibility range;
- clean removal without changing other packs.

Alpha 2 supplies the boundary and template only. Migration of existing skills and roles belongs to later phases.
