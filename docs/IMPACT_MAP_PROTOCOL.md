# Impact Map Protocol

Impact Map is required before implementation for non-trivial tasks.

## Required sections

- User intent.
- Relevant product area(s).
- Product knowledge loaded.
- Files likely involved.
- Files proposed to inspect.
- Files proposed to edit.
- Roles/skills/gates selected.
- Risks.
- Unknowns.
- Verification plan.
- Approval request.

## Rules

Do not implement before the Impact Map is accepted unless the task is Tiny/Micro, reversible, and explicitly requested.
