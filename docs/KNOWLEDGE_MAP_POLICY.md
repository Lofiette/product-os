# Knowledge Map Policy

Knowledge maps are navigation tools, not documentation dumps.

## Do

- Preserve evidence.
- Mark confidence.
- Mark unknowns.
- Link to narrower artifacts.
- Keep parent maps focused on routing.
- Update only affected artifacts after a task.

## Do not

- Copy whole child maps into parent maps.
- Turn area maps into implementation walkthroughs.
- Treat line counts as hard truncation rules.
- Create flow maps without enough evidence.
- Record guesses as facts.

## Oversized artifact response

If an artifact grows beyond its target range:

1. Do not cut important content.
2. Identify lower-level detail.
3. Propose child artifact or context packet.
4. Replace parent detail with a link and short summary.
5. Ask approval if creating a new artifact category.
