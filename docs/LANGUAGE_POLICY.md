# LANGUAGE_POLICY.md

- Answer the user in Russian by default.
- Keep durable control artifacts in compact English by default.
- Use the product UI language defined in TASK.md for product copy.
- Do not translate code identifiers, file names, import paths, or API names unless explicitly requested.
- If language affects UX copy, localization, or accessibility, activate UX Writer and Localization Specialist as needed.
