# New Task Protocol

When the user gives a new task, Codex should not immediately edit files.

## Steps

1. Classify task type and complexity.
2. Propose or create a local/current runtime ticket if the task is substantial.
3. Read `PRODUCT_MAP` and `KNOWLEDGE_INDEX` if present.
4. Select relevant area maps.
5. Select roles, skills, playbooks, and gates.
6. Propose bounded discovery.
7. Produce an Impact Map.
8. Ask approval before implementation.
9. Implement only after approval.
10. Verify.
11. Update affected runtime/product knowledge artifacts.
12. Compact CHRONICLE.
