# OWNERSHIP_MATRIX.md

Every meaningful decision has exactly one owner.

- Product value/scope: Product Strategist.
- Screen design solution: Product Designer.
- UI implementation fidelity: Design Engineer.
- Design-system compliance: Design System Guardian.
- Interaction/state behavior: UX Interaction Reviewer.
- User-facing language: UX Writer.
- Navigation/taxonomy: Information Architect.
- Service journey: Service Designer.
- Data visualization: Data Visualization Designer.
- Conversation flow: Conversation Designer.
- Technical architecture: Solution Architect.
- Frontend implementation architecture: Frontend Architect.
- Backend/API: Backend Architect / API Contract Guardian.
- Verification: QA Engineer.
- Diff review: Code Reviewer.
