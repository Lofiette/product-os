# Redesign / Migration Mode

Use this mode when an existing product is being substantially redesigned, migrated, or rebuilt.

## Required maps

- Current-state map.
- Target-state map.
- Delta map.
- Risk map.
- Approved deviations/decisions.

## Rules

- Preserve existing behavior unless explicitly changed.
- Separate current evidence from target intent.
- Do not mix visual reference fidelity with implementation proof.
- Use Impact Map before changes.
- Update only affected product knowledge artifacts after implementation.
