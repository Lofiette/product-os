# Codex Product Team 2.0 Release Notes

- Removed all character codenames.
- Introduced role-skill architecture.
- Added explicit subagent orchestration and approval policy.
- Added execution transparency: spawned vs simulated vs service.
- Added Product Designer and Design Engineer.
- Added Service Designer, Information Architect, Data Visualization Designer, Conversation Designer, Growth & Activation Strategist.
- Added design-system modes for no DS, emerging DS, component library, documented DS, and governed DS folder.
- Added Design Recon, UI quality gates, Design System Manifest schema, Visual QA loop, UI obvious errors checklist.
- Added scripts for raw UI value and component import heuristics.
