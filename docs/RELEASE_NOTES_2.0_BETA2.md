# RELEASE_NOTES_2.0_BETA2.md

## Codex Product Team 2.0 beta 2 — Culture, Taste & Anticipation Layer

### Added

- `docs/TEAM_CULTURE.md` for operational team values.
- `docs/TASTE_PROFILE.md` with good/bad examples and anti-taste.
- `docs/TASTE_REVIEW.md` as a blocking review gate.
- `docs/CREATIVE_TENSION.md` for controlled improvement critiques.
- `docs/EXPECTATION_ANTICIPATION.md` for proactive proposals that require approval.
- Skills:
  - `taste-calibration`
  - `taste-review`
  - `creative-tension-review`
  - `expectation-anticipation`
  - `example-taste-board`
- Templates:
  - `taste-profile.md`
  - `taste-review-report.md`
  - `creative-tension-brief.md`
  - `anticipation-proposal.md`
  - `example-taste-board.md`

### Changed

- `AGENTS.md` now includes operational culture, taste gates, anticipation discipline, and exact-agent-ID naming policy.
- `FIRST_PROMPT.md` now forbids personal/codename agent labels and proposes taste/anticipation workflows when relevant.
- `TASK.md` now tracks taste profile and anticipation proposals.
- `CHRONICLE.md` now tracks taste/anticipation decisions.
- Routing docs now include taste and anticipation triggers.

### Important

Beta 2 still treats taste as a decision constraint, not evidence. Creative and anticipation proposals must not change scope without user approval.
