# RELEASE_NOTES_3.0_BETA2.md

## Codex Product Team 3.0 Ultra beta 2 — Routing, Skills, and Runtime Coherence Hardening

This release hardens the 3.0 Ultra architecture after control audit.

### Fixed

- Removed stale 2.x version labels from runtime/config docs.
- Updated routing matrices for the 3.0 Runtime Kernel, Product Knowledge System, Safe Autonomy, and `frontend_engineer` implementation responsibility.
- Expanded critical 3.0 skills into operational workflows: new task protocol, bounded discovery, impact map, product knowledge onboarding, API/data shape prewarm, framework loading, knowledge update, greenfield onboarding, and freshness review.
- Clarified `TKT-000` as an intake placeholder rather than an active user task.
- Added staged-loading metadata to role indexes.
- Strengthened scenario tests and markdown scenarios for 3.0 runtime behavior.
- Added validator checks for stale labels and mirrored protocol drift.

### Core principle

3.0 beta 2 keeps the kernel lightweight, loads product knowledge by area, loads expert framework assets by task type, and prevents both context obesity and blind execution.
