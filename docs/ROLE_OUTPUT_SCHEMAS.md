# ROLE_OUTPUT_SCHEMAS.md

All role outputs must be compact and evidence-labeled.

Common schema:
- Context
- Findings
- Evidence / assumptions
- Decision or recommendation
- Blockers
- Handoff

UI role schemas are in templates:
- screen-design-spec.md
- design-recon-brief.md
- ui-fidelity-report.md
