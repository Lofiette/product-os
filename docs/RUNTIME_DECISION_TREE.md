# RUNTIME_DECISION_TREE.md

1. Classify task and complexity.
2. If existing repo: run repo-recon before architecture/implementation.
3. If UI/design affected: run design-recon before UI implementation.
4. If design system exists: classify DS mode and enforce DS gate.
5. Select roles by artifact ownership.
6. Select skills by method need.
7. Choose orchestration mode.
8. Ask approval before real subagent spawn.
9. Execute approved operation.
10. Verify through relevant gates.
11. Review at appropriate level.
12. Update TASK.md/CHRONICLE.md compactly.
