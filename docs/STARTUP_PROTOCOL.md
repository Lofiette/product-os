# Startup Protocol

## Goal

Restore enough exact state to choose the next safe operation without loading the whole framework or project history.

## Sequence

1. Read `AGENTS.md`.
2. Read `.cpt/runtime.yaml`.
3. Read `.cpt/current.yaml`.
4. Read `.cpt/task-index.yaml`.
5. Read `.cpt/runtime-summary.md`.
6. If referenced, load only the active task, micro change, lease, and latest checkpoint.
7. Validate state before acting if files were manually changed, recovered, or generated by an older runtime version.

## Valid empty state

```yaml
runtime_status: ready
current_task: null
current_micro_change: null
```

No placeholder ticket is required. `TKT-000` may exist as a system record but is not automatically active.

## Stop conditions

Stop and report `BLOCKED` when:

- current pointers reference missing files;
- task index contains duplicate IDs;
- an active lease belongs to another unit of work;
- checkpoint integrity fails;
- runtime summary revision differs from current state after explicit recovery;
- state schema is unknown or unsupported.
