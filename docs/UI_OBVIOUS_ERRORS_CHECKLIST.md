# UI_OBVIOUS_ERRORS_CHECKLIST.md

Run before finalizing UI work.

Blockers include:
- no clear primary action;
- competing primary actions;
- missing empty/loading/error/success/disabled states when relevant;
- form fields without labels or nearby errors;
- CTA text vague or misleading;
- visual hierarchy contradicts user task;
- custom duplicate of DS component;
- raw colors/spacing/radius when tokens exist;
- color as only meaning carrier;
- modal/dialog without safe close/cancel path;
- dangerous action without confirmation;
- responsive layout loses primary action;
- table/list without empty/overflow behavior;
- disabled action without explanation when user needs it.
