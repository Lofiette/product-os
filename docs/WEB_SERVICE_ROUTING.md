# WEB_SERVICE_ROUTING.md

Use for web services, SaaS modules, dashboards, internal tools, customer portals, and production-facing web applications.

## Routing by surface

### UI-heavy web service
Usually include:
- product_designer
- design_system_guardian
- design_engineer
- frontend_architect
- qa_engineer

Conditional:
- ux_writer for user-facing states and messages
- accessibility_specialist for production forms/dialogs/tables
- data_visualization_designer for dashboards/reports
- performance_engineer for heavy rendering or scale

### Full-stack web service
Usually include:
- product_strategist
- solution_architect
- frontend_architect
- backend_architect
- api_contract_guardian
- qa_engineer

Conditional:
- security_reviewer for auth, permissions, sensitive data, abuse risk
- privacy_compliance_reviewer for personal/sensitive data
- data_architect for persistent domain data
- devops_release_engineer for deployment/release

### Design-only module handoff
Usually include:
- product_designer
- information_architect
- design_system_guardian
- ux_writer
- design_engineer as feasibility/handoff reviewer
- qa_engineer for design QA

Do not implement code unless the user approves implementation.
