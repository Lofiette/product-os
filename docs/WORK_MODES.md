# WORK_MODES.md

Modes:
- Throwaway prototype: fast exploration, minimal durability, still no fake DS compliance.
- Design prototype: UI quality matters; backend/data may be fake; design recon/state matrix required.
- Technical PoC: prove feasibility; UX may be minimal but risks must be explicit.
- MVP: smallest valuable end-to-end slice.
- Production change: strict gates and tests.
- Bugfix: reproduce/isolate/fix/verify.
- Refactor: behavior preservation.
- Research: no implementation unless later approved.
- Review/audit: read-only by default.
