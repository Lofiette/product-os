# Scenario 10: opportunity_event_creative_improvement

## Description
A stakeholder or another department proposes a potentially better idea during planning

## Work mode
Opportunity event / improvement loop

## Complexity
Fast Lane/Standard depending on impact

## Required roles
- `intake_orchestrator`
- `team_architect`
- `product_strategist`
- `chronicle_keeper`

## Optional roles
- `ux_researcher`
- `cx_researcher`
- `market_researcher`
- `ux_interaction_reviewer`
- `ux_writer`
- `solution_architect`
- `experimentation_specialist`
- `consistency_auditor`

## Forbidden roles
- `incident_investigator`
- `devops_release_engineer`

## Required skills
- None

## Limits
- Max active roles: 8
- Max questions: 5

## Expected gates
- Classify event as OE-0..OE-4
- Record opportunity event if it changes decisions
- Creative outputs labeled as hypotheses
- Use at most one method from CREATIVE_METHODS.md per planning cycle unless user asks for ideation sprint
- No approved scope change without user approval
