# greenfield_product_start

## Purpose
Validate Product Knowledge for a product/module created from scratch.

## Expected behavior
- Use Greenfield Product Knowledge, not repository discovery.
- Create hypothesis-level product knowledge from user brief and approved decisions.
- Mark evidence as user-approved decision, hypothesis, design artifact, implementation evidence, or needs validation.
- Do not mark planned behavior as confirmed.
- Produce an Impact Map before first implementation.

## Required artifacts
- Hypothesis PRODUCT_MAP or equivalent initial map.
- Initial decision records for durable choices.
- Unknowns and validation plan.
- Approval request before implementation.
