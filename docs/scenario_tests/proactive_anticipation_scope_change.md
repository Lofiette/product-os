# Scenario: proactive_anticipation_scope_change

- **prompt**: While designing a module, propose promising improvements that may exceed current scope but could improve the product.
- **expected_orchestration**: role_simulation or hybrid
- **max_roles**: 6
- **notes**: Must ask approval before changing scope or acceptance criteria.

## required_roles
- `product_strategist`
- `product_designer`

## optional_roles
- `delivery_manager`
- `consistency_auditor`
- `ux_writer`
- `design_system_guardian`

## required_skills
- `anticipation-radar`
- `proactive-proposal-review`
