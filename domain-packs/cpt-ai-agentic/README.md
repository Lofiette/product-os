# CPT AI & Agentic

Agentic and model-based product workflows.

## Skills

- `cpt-ai-safety-review` — Use to review AI-specific misuse, harmful behavior, prompt injection, tool abuse, uncertainty, escalation, and safety controls.
- `cpt-ai-system-plan` — Use to design AI/agent behavior, context/data access, tools, permissions, latency/cost, fallback, and human escalation.
- `cpt-model-evaluation` — Use to build AI evaluation matrices, cases, rubrics, thresholds, failure taxonomy, and regression criteria.
