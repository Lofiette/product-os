# CPT Reference Taste Calibration

## Use when

- The user provides visual references, adjectives, examples, or an open-ended quality direction.
- Several design alternatives need disciplined critique.
- A product needs a visual direction that is not fully governed by an existing system.

## Do not use when

- The task has a fully governed spec and no subjective design decision remains.
- The goal is to copy a reference rather than derive transferable criteria.

## Required inputs

- References, good/bad examples, user adjectives, product/audience, design-system mode, constraints, and goal.

## Method

1. Separate what to learn from what must not be copied.
2. Inspect the reference's product context before transferring its surface treatment.
3. Extract layout, hierarchy, density, rhythm, typography, color/emphasis, component anatomy, interaction, content tone, motion, imagery, and emotional qualities.
4. Translate examples into transferable principles, mechanisms, anti-patterns, and observable acceptance criteria.
5. Classify must-match, may-adapt, and must-not-copy aspects.
6. Distinguish durable craft from dated style or technology.
7. Critique alternatives against user goal, authoritative system, evidence, accessibility, maintainability, and the taste contract rather than personal preference.
8. Get approval for material deviations before implementation.

## Output contract

Produce a compact artifact containing:

- `Reference/Taste Contract.`
- `Good/bad example board with derived rules and anti-rules.`
- `Observable taste dimensions and critique matrix.`
- `Selected direction, approved deviations, and unresolved interpretation.`

## Evidence standard

- A reference is a constraint or inspiration only as explicitly agreed.
- "Feels premium," "friendly," "minimal," or "modern" must be translated into observable criteria.
- Reference taste cannot override product behavior, accessibility, or authoritative design-system rules without approval.
- References calibrate expression; they do not replace UI craft foundations.

## Stop and escalate

- References conflict and priority is unknown.
- The reference context is materially different and transfer risk is unresolved.
- Copying would violate IP or brand constraints.

## Failure modes to avoid

- Saying "looks similar" without a delta table.
- Copying surface styling while missing interaction hierarchy.
- Treating a current trend as timeless quality.
- Using adjectives without observable criteria.
