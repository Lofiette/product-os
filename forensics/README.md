# Forensic evidence branch

This branch is intentionally separate from `main`. `main` ends at the clean Product OS `v4.0.0` source tree.

This branch preserves:

- 77 non-training generated artifacts byte-for-byte;
- 9227292 bytes of preserved generated evidence;
- original historical ZIP releases and audits;
- forensic manifests, checksums, file maps, and missing-asset registries;
- human-readable reconstruction documentation.

It intentionally excludes raw account conversation exports, user screenshots, and personal training materials.
