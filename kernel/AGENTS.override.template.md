# AGENTS.override.md — Local Runtime Overlay Template

This local override is a startup gate, not a replacement for the product-team framework.

Use local ignored runtime memory if present:

- `.codex-runtime/CURRENT.md`
- `.codex-runtime/TASK_INDEX.md`
- `.codex-runtime/CHRONICLE.md`
- `.codex-runtime/tasks/*`
- `.codex-runtime/product/*`

Do not use root `TASK.md` or root `CHRONICLE.md` as active memory by default.

For concrete tasks, use New Task Protocol: local ticket -> product knowledge -> bounded discovery -> Impact Map -> approval -> implementation.

Do not load the whole framework. Load relevant roles, skills, playbooks, and gates by task type.
