# Product Knowledge Failure Modes

- **Encyclopedic parent:** Product Map or Area Map absorbs child-level detail. Split by existing artifact type and preserve links.
- **Confidence laundering:** generated prose or indirect evidence is presented as confirmed behavior. Keep the claim inferred or hypothesized.
- **Target/current collapse:** desired redesign behavior overwrites the current baseline before implementation.
- **Full remap after local change:** freshness scan broadens beyond path/dependency impact.
- **Projection as source:** generated Markdown is edited instead of canonical YAML.
- **Transcript dumping:** temporary task logs are copied into durable artifacts.
- **Silent staleness:** source files change without review triggers or dependency propagation.
- **Secret storage:** credentials, customer data, or restricted values are copied into canonical knowledge.
- **Vector-snippet authority:** semantic recall is treated as evidence without opening the original source.
- **Hard-size truncation:** useful evidence or unknowns are deleted to satisfy a length target.
- **Unowned knowledge:** no role is accountable for review and maintenance.
- **Completion bypass:** a Standard Task closes without assessing whether durable knowledge changed.
