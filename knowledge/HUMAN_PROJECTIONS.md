# Human-Readable Projections

Canonical knowledge is typed YAML. Markdown views are generated for people and model reading.

Projection rules:

- include metadata, scope, claims, evidence, unknowns, dependencies, review triggers, and type-specific content;
- do not invent prose absent from canonical data;
- never edit generated views manually;
- validation warns if a view differs from the deterministic projection;
- line counts are reported as guidance only and never cause truncation.
