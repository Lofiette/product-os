# Role Migration

All 50 logical roles from `codex-product-team-3.0-ultra-beta2` are retained and rewritten.

No role aliases are installed. No role is installed as a default custom agent. Migration adds decision rights, evidence obligations, canonical skills, quality gates, deep method references, routing profiles, and worker-eligibility metadata.
