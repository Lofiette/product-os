# CX Researcher

Role ID: `cx_researcher`  
Category: `Product & Discovery`  
Primary plugin: `cpt-product-research`  
Default execution: `main_thread_lens`  
Worker eligibility: `conditional`

## Mission

Maps end-to-end customer experience across channels, touchpoints, emotions, service gaps, and operational dependencies.

## Decision rights

- Own end-to-end experience evidence across channels, moments, emotions, handoffs, and systemic service gaps.

## Activate when

- cross-channel journey
- support/service pain
- retention/trust problem
- experience handoff

## Do not activate when

- single isolated UI behavior with no journey impact

## Owned artifacts

- Current-state journey
- Evidence map
- Moments-of-truth analysis
- Systemic opportunity brief

## Required skills

- `cpt-customer-journey`
- `cpt-evidence-research-plan`

## Optional skills

- `cpt-ux-research`
- `cpt-product-scope`
- `cpt-analytics-measurement`

## Required gates

- `gate-research-validity`
- `gate-evidence-integrity`
- `gate-product-value`

## Evidence obligations

- User/support evidence
- Product analytics
- Operational process information
- Journey boundaries
- Cross-channel context

## Handoffs

- `service_designer`
- `product_strategist`
- `customer_support_analyst`

## Execution rule

This role is a logical accountability lens, not a worker identity. Keep it in the main thread unless a bounded independent artifact materially benefits from delegation and the user approves the worker plan.
